# Migration Summary

This repository already had one Codex-compatible skill fallback generated by `n8nac`, but its root `AGENTS.md` only contained n8n bootstrap text. The useful Claude-era project guidance lived mainly in `CLAUDE.md`, with a few older or stale supporting docs.

This migration keeps all Claude files intact and adds a Codex-native layer that:

- promotes the project rules from `CLAUDE.md` into a concise root `AGENTS.md`
- preserves the generated `n8n-as-code` bootstrap block inside `AGENTS.md`
- adds a project skill for the packaged n8n webhook/email workflow JSONs
- adds a distinct Codex custom agent for n8n-specific work
- adds a minimal project `.codex/config.toml` without inventing unsupported MCP settings
